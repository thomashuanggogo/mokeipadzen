# 墨課 Moke

免費開源的白板錄課 App——已退役 [Doceri](https://web.archive.org/web/20241203232132/http://doceri.com/) 的精神繼承者。在白板上書寫，每一筆都變成可重播的時間軸事件。

**[English](README.md)**

**線上試用**：https://thomashuanggogo.github.io/moke-whiteboard/（iPad Safari 橫屏開啟即可）

## 為什麼做墨課？

Doceri（2011–2022）證明了這個模式：白板上的每一筆都是時間事件，配合暫停標記掌握課堂節奏。然後它退役了。開源世界始終沒有補上這個缺口——GitHub 上沒有任何專案提供「筆跡級時間軸重播」的教學工具。墨課就是來填這個空的。

墨課做對的三件事：

1. **誠實的時間**——時鐘只在書寫時走。下筆計時、提筆即停，發呆的時間不會灌進課程長度。
2. **擦除看得見**——橡皮擦是時間軸事件，不是刪除。重播時看得到字先出現、再被擦掉。（復原不一樣：復原是「那筆沒發生過」，直接從時間軸移除。）
3. **免費、本地優先**——無帳號、無訂閱、無雲端。資料存在瀏覽器 IndexedDB，伺服器只提供靜態檔案。

## 功能

- ✏️ 畫筆、螢光筆、橡皮擦、圖形（直線、箭頭、矩形、三角形、平行四邊形、橢圓、座標軸）、文字、雷射筆
- 📏 直尺、量角器、圓規
- 🪢 套索框選——整組移動或旋轉，旋轉不變形
- 🚩 段落標記綁筆跡——播放到標記自動停，供學生抄筆記
- ⏱️ 每頁獨立時間軸、動作時間時鐘
- 🖼️ 圖片底圖＋調整模式（縮放／移動）
- 📄 本頁存 PNG、全部存 PDF；💾 課程 JSON 存檔／匯入
- 📡 WebRTC 即時投影分享（點對點）
- 📱 PWA——可安裝、離線可用

## 快速開始

免建置、免安裝依賴，就是靜態檔案：

```bash
npx serve .
# 或
python3 -m http.server 8000
```

用瀏覽器打開（建議 iPad Safari 橫屏）。就這樣。

部署：把整個資料夾丟到任何靜態主機（Cloudflare Pages/Workers、Netlify、GitHub Pages）。建議用 HTTPS（麥克風、分享功能需要）。

## 架構

**事件溯源畫布**：畫布不是一張圖，而是一條事件流。`state = fold(events ≤ t)`——確定性重播、無損拖曳、乾淨的復原。

- `js/board.js`——畫布、工具、手勢、渲染（Catmull-Rom 平滑）
- `js/lesson.js`——時間軸引擎、每頁時鐘、重播控制器
- `js/app.js`——介面邏輯
- `js/share.js`——WebRTC 投影分享
- `js/vendor/`——內嵌第三方庫（jsPDF、PeerJS、QRCode，皆 MIT/Apache-2.0）

座標全部正規化（0..1），與解析度無關。設計規格：[`ENGINE_SPEC.md`](ENGINE_SPEC.md)。
